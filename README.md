## 🏦 Bank Loan Analysis | MySQL + Power BI

## 📌 Project Overview

This project analyzes a real-world **Bank Loan dataset sourced from Kaggle** to uncover insights into loan performance, borrower risk, and portfolio health.

The goal of this project is to demonstrate end-to-end data analysis skills — from database creation and SQL querying to interactive dashboard development in Power BI.

---

## 🛠 Tools & Technologies

* **MySQL** – Database creation, data cleaning, and analysis
* **Power BI** – Data modeling, DAX, and dashboard development
* **Excel** – Initial data review
* Dataset Source – Kaggle

---

## 🗂 Project Workflow

1. Imported raw loan dataset into MySQL
2. Created and structured relational tables
3. Performed data cleaning and transformations
4. Wrote SQL queries to solve business problems
5. Connected MySQL to Power BI
6. Built interactive dashboards with KPIs and time intelligence

---

## 📊 Dashboards Created

### 1️⃣ Summary Dashboard

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average Debt-to-Income Ratio (DTI)
* Good Loans vs Bad Loans
* Month-to-Date (MTD) & Month-over-Month (MoM) analysis

### 2️⃣ Overview Dashboard

* Monthly Loan Trends
* Regional Analysis by State
* Loan Term Distribution
* Employment Length Analysis
* Loan Purpose Breakdown
* Home Ownership Analysis

### 3️⃣ Details Dashboard

* Loan-level comprehensive data view
* Performance tracking
* Borrower insights

---

## 📈 Key Insights

* 38.6K Loan Applications Analyzed
* $435.8M Total Funded Amount
* $473.1M Total Amount Received
* 86% Good Loans vs 14% Bad Loans
* Clear visibility into risk patterns using DTI & Interest Rate trends
